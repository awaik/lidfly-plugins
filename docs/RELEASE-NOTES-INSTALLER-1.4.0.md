# LidFly Plugin Lapki 1.4.0

Приложение LidFly получило новый интерфейс и новое имя — `LidFly Plugin Lapki`.
Установка плагина Codex и подготовка папки для Claude Desktop теперь разделены
на понятные пошаговые сценарии.

## Важно при обновлении с 1.3.0

- Миграция `1.3.0 → 1.4.0` на Windows будет проверена командой тестирования
  после публикации релиза. До результатов проверки не удаляйте старую версию,
  пока не убедитесь, что новая версия запускается и работает.
- **Windows:** версия 1.4.0 устанавливается как отдельное приложение для
  текущего пользователя. После запуска и проверки новой версии удалите
  `LidFly Codex Plugin Installer` через **Параметры → Приложения → Установленные
  приложения**.
- **macOS:** обновление внутри приложения сохраняет прежнее имя `.app`. Чтобы
  перейти на новое имя, установите `LidFly Plugin Lapki` из актуального DMG,
  запустите его, затем удалите старое `LidFly Codex Plugin Installer.app`.
